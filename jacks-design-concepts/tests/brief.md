# Test brief

**Brief:** A notification center panel for an existing B2B analytics web
dashboard. Users must see unread alerts (threshold breaches, scheduled report
completions, teammate mentions), triage them (dismiss, snooze, assign), and
jump to the source chart or report.

**N:** 3 (kept small for test cost; skill would say 4-5 for a section).

**House style:** greenfield. Invent the palette.

**Territories (fixed across reps and variants):**

| Concept | Axis | Instruction |
|---|---|---|
| 01 | Spatial model | Diverge from the default dropdown list. |
| 02 | Interaction model | Diverge from the default click-to-open, click-to-dismiss. |
| 03 | Information density | Diverge from the default medium-density list. |
